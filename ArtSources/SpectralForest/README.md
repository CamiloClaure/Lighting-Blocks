# Editable forest sources
Open WisdomTree-authored.blend to edit the source-derived tree material groups and mesh. AllModels.blend is the original CC0 nature pack source. The PNG is the user-supplied visual reference.

Blender scripts generate into Exports/ beside these files. build_nature.py regenerates ordinary tree LODs. refine_wisdom.py replays the four-view authored semantic selections and surface-edge filament paths against the Wisdom Tree. It saves the blend and can overwrite manual face-material edits, so duplicate the blend before replaying it. Copy approved FBX/JSON derivatives from Exports into Assets/LightingBlocks/Art/SpectralForest/ProcessedModels, then run Apply Spectral Forest in Unity.

Licenses, source hashes, final prefab mappings, animation mappings and import notes are in Assets/LightingBlocks/Art/SpectralForest/Documentation.
